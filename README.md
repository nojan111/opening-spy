# Opening Spy

See which chess openings any Chess.com or Lichess player uses, how often, and how they score with them. Then replay any game on a board with Stockfish, accuracy, clocks, and a slightly judgy little coach.

Live: https://nojan111.github.io/opening-spy/

Everything runs in your browser. Games come straight from the public Chess.com and Lichess APIs.
